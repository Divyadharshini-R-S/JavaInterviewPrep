# JavaInterviewPrep
Repo to maintain the classic java programs and DSA programs for interview
# Java commands to save the .class file in bin path and run from there
cd respectiveFolderName
javac -d .\bin javaFileName.java
java -cp .\bin javaClassName

# About
This Repo is created for learning purpose which organized in the following structure:
    #Classic-Java-Coding-Program
        -This folder will contain the classic java interview programs, which does not include any DSA or pattern programs.
        -Example: Leap Year or not , Prime or not, Odd or even etc...
    #Java-DSA-Program
        -This folder will contain the DSA problems which will be categorized by subtopics
        -Example: Array, List, ArrayList, HashMap etc...
    #Java-Pattern-Program
        -This folder will contain the pattern problems
        -Example Triangle Star Pattern, Pyramid Star Pattern etc...
